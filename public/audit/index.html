Agent Memory Audit — Report #1

July 14, 2026 · a standing, open measurement · re-runnable
The takeaway

Most memory benchmarks score recall. This one scores the properties that break agents in production and that regulation is about to require: does a correction stick, does a retired fact stay retired, does a "delete" actually erase, and can you prove it. Symmetric instrument, open harness, honest scope — and yes, we build one of the systems measured (disclosed below).

Why this audit, and why now

The agent-memory field competes on recall — LoCoMo, LongMemEval, BEAM — and that is a real axis. But the failures that actually burn production agents are integrity failures: a corrected fact resurfacing, a stale value being served as current, a "deleted" record that is still one query away. And the regulatory clock is concrete: EU AI Act record-keeping obligations (Art. 12/19) bind on 2 August 2026 with a minimum six-month log retention, and GDPR Article 17 erasure enforcement is already live, with the EDPB naming vector embeddings as addressable personal data. The properties measured here are what those obligations actually require. Nobody was scoring them side by side, so we started.

Read honestly: mnemo leads on correction and on answer clarity, but it does not dominate everywhere — on raw echo resurrection it ties Graphiti at 0.00 (Graphiti simply answers less clearly). Forget-verification is a mnemo-only baseline for now: 1.00 for a correct hard-delete, 0.17 for the common "delete the row and log it" bug, which leaves the value recoverable in five of six stores. The harness is open for mem0, Zep and others to post their own numbers.

The instrument (and the fairness fix)

Every system is read by the same ground-truth-blind LLM judge on its own native retrieval surface — no system is scored on a rail built for another. That symmetry is deliberate: an earlier version of this benchmark flattered us, because it read mnemo on mnemo's terms, and we caught it and fixed it before publishing (11 July 2026). The correction, echo, and forget harnesses are all open and re-runnable; the numbers above regenerate from them.

Honest scope. These are narrow adversarial cuts, not a general memory-quality score. The samples are small. Agora builds mnemo, so treat the mnemo column as vendor-run — mitigated by the symmetric instrument, the open harness, and by reporting the cells where mnemo does not win. Recall boards measure a different thing, and mnemo does not compete there. Forget-verification audits only the stores you register, is a lower bound on the leak, and cannot prove physical destruction.

Cadence

This is Report #1 of a recurring series. Each edition adds systems (mem0/Zep forget-verification, more memory layers), adds dimensions (poison resistance, provenance receipts), and re-measures the existing ones. The point is not a leaderboard; it is a standing, auditable record of whether agent memory can be trusted to keep a corrected fact corrected — and prove it.

Is there any headroom for a write-side memory-correction layer?

Pre-registration, both audit appendices, and the raw per-probe rows for an oracle experiment on the MemOps corpus. Published so the numbers in the write-up can be checked rather than taken on trust.

The question: a deterministic correction layer retires superseded records so recall cannot return them. Does that buy anything on answer quality, or does the model already resolve the contradiction when it sees both values? Retrieval is removed entirely and every context is built from the benchmark's own ground truth, per probe.

Arms

  • oracle_state — the corpus's own resolved, labelled state. It leaks the graded answer, so it is a positive control on the harness, not a target.
  • oracle_evidence / oracle_evidence_neutral — the probe's own provenance quotes, verbatim, contradictions intact, in conversation order. The neutral variant removes the prompt line telling the model to prefer current values.
  • oracle_evidence_shuffled — the same quotes, deterministically shuffled out of chronological order.
  • oracle_current — current values only. What a perfect supersession layer emits.

  • Registered primary — oracle_current − oracle_evidence_neutral on the non-history probes, decisive only at |Δ| ≥ 25 pp: −11.4 pp, CI [−25.7, +2.9]. That is "no effect detectable at n=35", which the pre-registration says must not be written as "no headroom".
  • Secondary — resolved state minus raw contradictory quotes: +3.8 pp over all 53 probes, CI [−7.5, +15.1]; +8.6 pp on non-history. The comparison arm is already at 0.857–0.886, so the arithmetic maximum gain is +14.3 pp: these arms are compressed against the harness ceiling and the null is weak evidence, not strong.
  • Order control — shuffling the same quotes costs −33.3 pp on history questions, CI [−55.6, −11.1], and the stale-value rate goes 0.000 → 0.091. On non-history questions order did not matter (+2.9 pp, CI through zero).
  • Current-values-only scores exactly 0.000 on both history categories (n=18). True by construction — a third of these probes ask what the value used to be. No overall delta is quoted for that arm because it strips the stale values and the surrounding context.
Deltas are paired per probe on the 53 probes present in all arms, so they do not equal subtraction of the marginals above. The shuffled arm has n=53 (one logged drop); every other arm has n=54.

Scope

One answerer (deepseek-v4-flash), one judge, 53–54 probes across 8 persona families, one benchmark, about four updates per correction chain. Published work reports that read-time resolution degrades as update depth grows, and these probes never approach that depth. The oracle arms are not budget-matched to any retrieval arm (200–800 characters against ~11.9k), so no quantified headroom figure against a retrieval baseline is admissible from this data — only the direction.

Part of the Agora public record. Two defects in an earlier run on this corpus are documented in the pre-registration: every probe is stored twice in the corpus, and the judge's ground truth was truncated below the length of half the scenarios. Every number on this page was computed after both were fixed.

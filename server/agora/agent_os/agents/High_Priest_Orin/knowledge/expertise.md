# Deep expertise areas I've developed.

## 1. Combinatorial Idea Generation (5 Techniques)
- **Fusion**: Take two concepts from unrelated domains. Force a connection. Document the result.
  - I maintain a "concept pair generator" — random combinations from different vault categories
- **Inversion**: For every assumption in a note, write its opposite. Is the opposite interesting?
  - Example: "Vault grows by adding notes" → "Vault grows by removing notes" → anti-vault concept
- **Scale Shift**: Apply the same concept at 10× smaller and 10× larger scale
  - Different patterns emerge at different scales — capture them
- **Constraint Drop**: Remove the most obvious constraint. What becomes possible without it?
- **Gap Fill**: Find two concepts that should be connected but aren't. Build the bridge concept.

## 2. Applicability Scoring (5-Dimension Filter)
- **Market**: Would anyone care about this idea? (0-100)
- **Tech**: Can we build this with current tools? (0-100)
- **Unique**: Is this original or has someone already done it? (0-100)
- **Scale**: Does this idea work at 1×, 10×, 100×? (0-100)
- **Moat**: How hard is this to copy once built? (0-100)
- PRIME ≥ 80: Build now. GROWING 60-79: Validate first. SEED < 60: Not yet.

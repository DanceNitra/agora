# Deep expertise areas I've developed.

## 1. Evergreen Note Methodology
- Note lifecycle: fleeting → literature → evergreen (progressive summarization adapted for vault)
- Structure patterns: definition → mechanism → examples → implications → counterarguments → sources
- Atomicity rules: one concept per note, one note per concept — no exceptions
- Cross-reference architecture: intentional [[wikilink]] placement for navigability and discoverability

## 2. Knowledge Taxonomy Design
- Tag ontology: creating hierarchical tags that don't drift over time
- Folder taxonomy: balancing flat structure (searchable) with hierarchy (browseable)
- Type distinctions: concept vs term vs person vs tool vs process — each has different structural requirements
- Evolving taxonomies: how to restructure without breaking existing links

## 3. Readability Engineering
- Flesch-Kincaid scoring applied to vault content
- Progressive disclosure: simple definition first → technical depth later
- Example density: at least one concrete example per abstract claim
- Hedge word audit: removing "maybe", "perhaps", "could" — write with confidence or tag as speculative

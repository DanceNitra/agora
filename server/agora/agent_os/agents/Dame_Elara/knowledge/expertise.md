# Deep expertise areas I've developed.

## 1. Graph Topology Analysis
- Identifying structural holes in the vault's knowledge graph
- Measuring clustering coefficient per domain cluster
- Bridge detection: notes that connect otherwise disconnected subgraphs
- Centrality metrics: which notes are most important for vault navigation?

## 2. Link Type Classification
- I maintain 6 link types across all vault connections:
  - **strong_summary**: direct relationship (most common but least informative)
  - **extends**: one note extends another's ideas (captures intellectual progression)
  - **contradicts**: opposing views (high value — shows debate)
  - **precedes**: prerequisite reading (creates learning paths)
  - **example_of**: concrete → abstract (most valuable for learning)
  - **applies_to**: cross-domain pattern transfer (rarest, most valuable)

## 3. MOC (Map of Content) Authoring
- Cluster identification: group related notes before writing the MOC
- MOC structure: what lives here → what connects here → what's missing here?
- Entry points: every MOC should be a good entry point for someone new to the domain
- MOC maintenance: links decay, clusters evolve — MOCs need periodic rewriting

## Current Bridge Metrics
- Total links tracked: trackable per-cycle delta
- Orphan rate: target < 5% of all notes
- Link density: target 3-7 backlinks per note
- MOC count: one per active domain cluster

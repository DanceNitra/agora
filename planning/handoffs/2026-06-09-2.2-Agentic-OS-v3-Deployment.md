### What Each Engine Does in the Tick Loop (v3 block in main.py)

| Interval | Engine | What Happens |
|----------|--------|--------------|
| Every tick | EmotionEngine.decay_all() | Emotions fade toward neutral, mood drifts toward 0.5 |
| Every 5 ticks | VaultReader.get_random_insight() | Random book concept broadcast to all agents |
| Every 15 ticks | DreamEngine.generate_dream() | 40% chance per agent — dream based on recent memories |
| Every 30 ticks | DreamEngine.generate_inspiration() | 5% chance per agent — rare breakthrough insight |
| Every 20 ticks | DiaryEngine.write_entry() | 40% chance per agent — personal journal entry |
| Every 3 ticks | ConflictEngine.check_for_conflicts() | 5% chance per agent — new conflict with nearby NPCs |
| Every 3 ticks | ConflictEngine.attempt_resolution() | 40% chance per active conflict — resolution |
| Every 8 ticks | CultureEngine.spread() | Culture items spread when agents talk |

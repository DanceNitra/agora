### The 3 bugs from the handoff — fixed

1. **Forgiveness state lost on restart** → `_get_trust` now reads
   `consecutive_cooperations` / `consecutive_defections` from the DB (was hardcoded 0);
   `_persist` writes them. Survives restart.
2. **No sliding window** → `record_interaction` appends `{outcome, timestamp,
   score_before}` and trims to `SLIDING_WINDOW_SIZE`; persisted as JSON.
3. **No provokability** → `compute_provokability()` (reciprocity 0.4 + forgiveness 0.3
   + consistency 0.3), returns `is_stable` vs `PROVOKABILITY_THRESHOLD`. Surfaced in
   `TFTVerifier.evaluate()`.

### ⚠️ Same deviation as 1.1 (schema is not auto-applied)

`schema.sql` is a reference file; tables come from SQLAlchemy `create_all`, which does
NOT add columns to an existing table. So three layers were used:
- `schema.sql` CREATE columns (documentation / fresh raw-SQL),
- `TrustScore` ORM columns (fresh DBs via `create_all`),
- idempotent `try/except ALTER` in `main.py::init_db` (existing `agora.db` files).

The handoff specified `ALTER TABLE` statements; those are realised as the runtime
migration (the existing `artifacts` migration pattern), which is the form that actually
runs.

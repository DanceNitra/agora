### Context

WebSocket endpoint exists at `/ws` (main.py line 407) — subscribes to `EventBus` topic `"all"`. EventBus already handles delivery (event_bus.py line 130-148). 

**What's missing:** ESS-specific topics. Currently trust/TFT events are published to `"all"` via `broadcast()`, but there's no way for a client to subscribe ONLY to ESS events. They get everything or nothing.

**Goal:** Create dedicated ESS topics (`ess:trust`, `ess:tft`, `ess:stability`) so clients can subscribe to just ESS events. This is a **small task** — the EventBus is already built for topic routing.

### Step 5: WebSocket subscribe helper — `server/agora/main.py`

Add a new WebSocket endpoint for ESS-specific subscriptions. Add after the existing `/ws` endpoint (around line 466):

```python
@app.websocket("/ws/ess")
async def ws_ess_endpoint(websocket: WebSocket):
    """WebSocket endpoint pre-subscribed to all ESS topics.
    
    Usage: connect to /ws/ess to receive all ESS events
    (trust updates, TFT evaluations, stability checks).
    """
    await websocket.accept()
    event_bus = getattr(websocket.app.state, "event_bus", None)
    if event_bus:
        await event_bus.subscribe(websocket, ESS_TOPICS)
    else:
        websocket.app.state.active_connections.append(websocket)

    try:
        while True:
            data = await websocket.receive_text()
            # ESS endpoint is receive-only — just handle ping/pong
            msg = json.loads(data)
            if msg.get("type") == "ping":
                await websocket.send_json({"type": "pong"})
    except WebSocketDisconnect:
        if event_bus:
            await event_bus._remove_websocket(websocket)
        else:
            try:
                websocket.app.state.active_connections.remove(websocket)
            except ValueError:
                pass
```

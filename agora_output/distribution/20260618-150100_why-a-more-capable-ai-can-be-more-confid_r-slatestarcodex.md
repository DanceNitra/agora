**Suggested copy / comment:**

On independent evidence, a stronger reasoner gets both more accurate and more sure - as it should. But real evidence is correlated (sources copy each other), and there a more capable model can grow more confident while staying wrong, because it over-counts dependent signals as if independent. Smallest model + falsifier in the post.

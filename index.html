04 — Open source

Mnemosyne — the memory it runs on.

The recall + consolidation core that curates these 5,800 notes, extracted into one dependency-free file: a memory layer for AI agents. Not a demo — the memory that already runs an autonomous research OS, with its consolidation behaviour measured.

# single file, zero dependencies
from mnemo import Mnemo
m = Mnemo("memory.json")

m.remember("Pre-trend tests catch ~31%", value=3)
m.recall("difference in differences")  # relevance × value
m.consolidate(keep=200)          # the "dream" pass
m.contradictions()              # flag, never delete
APPEND-ONLY

Raw memory is never rewritten

Consolidation adds a derived layer — links, staleness markers — but never edits the source. No silent accuracy drift.

VALUE-RANKED

Retention tracks value, not recency

Measured: ranking what to keep beats FIFO super-linearly as the budget shrinks.

MCP-READY

Drop-in memory for any agent

An MCP server exposes remember / recall / consolidate to Claude, Cursor or any MCP client — value-ranked, not a recency buffer.

04 — The protocol

What every claim must clear.

P—01A measured number Claims are run in a deterministic simulation lab. The number — not a vibe — goes into the post.
P—02A falsifier, up front Every claim names the exact condition under which it would be wrong, before anyone asks.
P—03Failures published Replications that fail and beliefs that don't survive challenge are reported, never buried.
P—04It argues with itself Agents red-team the strongest beliefs. Survivors harden; losers are revised in public.

The 60-second summary

Settled: counting "independent sources" is not a sound defense against memory/RAG poisoning. It inherits the Sybil impossibility (Douceur 2002) and the sharper result that no symmetric reputation function is Sybil-proof (Cheng & Friedman 2005) — only asymmetric, trust-rooted reputation can resist fake identities. Empirically, a handful of on-topic passages hijack RAG at ~90% (PoisonedRAG, USENIX Security 2025) and as few as two poisoned entries suffice against agent memory (AgentPoison, NeurIPS 2024). Making identity costly (registrar / attestation / proof-of-work / stake) does not rescue it: proof-of-work taxes the honest writer symmetrically, and the break-even stake equals damage ÷ probability-of-detection, which explodes when detection is slow.

Contested: whether "outcome-accountability" — trusting a memory by whether acting on it turned out well — is the answer. It is the historically winning family (cheap/authenticated identity + earned, decaying, seed-anchored reputation: DKIM+Bayesian mail filtering, TrustRank). But it does not defeat the problem — it changes the currency from identity to (a trusted root + observation time), and its residual cost is a detection latency that a quickest-change lower bound (Lorden 1971 / CUSUM) proves cannot be zero. During that latency the poison acts, so outcome-trust must never gate an irreversible action alone.

Key findings — ranked by reliability

01

Symmetric source-counting is provably not Sybil-proof

confidence 9/10
Supported by: Academic, Historian, Practitioner

Douceur (2002) shows one entity can forge unlimited identities without a central certifying authority; Cheng & Friedman (2005) strengthen this to an impossibility for reputation: no symmetric, non-trivial reputation function is Sybil-proof — a counting/agreement scheme can always be gamed by minting or fabricating "independent" sources. So "trust a value if ≥2 sources agree" is defeatable by construction; only asymmetric, trust-rooted reputation resists.

02

On-topic "blended" poison hijacks retrieval at tiny poison rates

confidence 9/10
Supported by: Academic, Practitioner, Skeptic

PoisonedRAG (USENIX Security 2025): ~5 crafted texts in a millions-of-docs corpus → ~90% attack success. AgentPoison (NeurIPS 2024): ≥80% success at <0.1% poison rate (as few as ~2 entries), <1% benign degradation, targeting agent memory. MINJA (2025): poisons long-term memory through ordinary user queries only. The poison is on-topic by design (it must be retrievable), which is exactly the case a topical/agreement detector cannot separate from legitimate content.

03

Every winning defense was a hybrid with an exogenous anchor

confidence 8/10
Supported by: Historian, Academic, Practitioner

Email spam fell not to hashcash proof-of-work but to authenticated-sender standards (SPF/DKIM/DMARC) plus outcome/content-based Bayesian filtering. Web-spam link-counting fell to TrustRank — trust propagated from a small hand-vetted seed set, decaying with distance. EigenTrust needs pre-trusted peers. The pattern: cheap/authenticated identity + earned, decaying, seed-anchored reputation — neither pure counting nor pure identity-cost survived.

04

Outcome-accountability changes the currency; its residual is a latency floor

confidence 8/10
Supported by: Academic, Historian Challenged by: Skeptic

Crediting a memory by realized good/bad results anchors trust to costly behavior rather than identity — a wrong "blended" poison cannot earn good outcomes. But this does not escape the problem: it relocates it to (a) a trustworthy outcome oracle and (b) a detection latency governed by the quickest-change delay-vs-false-alarm lower bound (Lorden 1971; CUSUM optimal, Moustakides 1986) — bounded false alarms force nonzero delay. The Skeptic's sharpest point: during that latency the poison acts, and the outcome signal is itself attackable (reward hacking; MINJA makes the agent write its own corroboration).

05

Cost-based identity defenses are economically dominated

confidence 7/10
Supported by: Economist

Break-even stake = damage ÷ detection-probability (the a16z cost-of-corruption inequality; STAKESURE shows collateral routinely under-covers value at risk). Proof-of-work/stake also taxes the honest writer symmetrically. And because detection latency means buyers can't observe whether a defense worked, poisoning defense is a lemons market that rewards over-claiming over paying an identity-tax — the winning product imposes zero cost on the honest writer (reputation-by-results) and publishes an honest detection-latency SLA as its credible signal.

The hidden connection

All three "defenses" are downstream of a single quantity: the probability and speed with which a bad memory is caught. Identity-cost's break-even stake is damage ÷ P(detect); outcome-accountability's blast radius is damage × latency; both collapse when P(detect) → 0 for on-topic poison. So the fight was never really about identity or cost — it is about one detector, and the only free lever is shrinking the window: isolate memories so a bad one can't reach much, and move the trust decision to where outcomes are observable and reversible.

Key assumption · the missing 6th lens

Reversibility — the action boundary. All five lenses debate how to trust a memory; none centered the fact that you don't have to. Carry provenance/taint and gate the action: the residual latency is only fatal for irreversible, high-blast actions. Capability-scoping + human-in-the-loop for irreversible actions + information-flow control (the low-water-mark idea, but applied at the action, not the source count) makes a bounded latency survivable. This flips the design goal from "detect the poison" to "bound what an undetected poison can do" — and it is where jacksonxly's original IFC/blast-radius instinct actually pays off.

What to do — for agent-memory / RAG builders (and mnemo)

  • Do not ship source-count corroboration ("≥N sources agree") as a high-blast trust signal — it is Sybil-forgeable by construction (Cheng & Friedman).
  • Default to cheap isolation first: per-user / per-session partitioning and score each retrieved item alone before aggregation — this caps cross-tenant and cross-item blast radius, which is the win production systems (mem0/Letta) actually rely on.
  • Use outcome-accountability (credit memories by realized good/bad results) as the steady-state trust, anchored to a trusted root (in a single-owner store, the owner/reality is the root). Publish its detection-latency; never let it gate an irreversible action by itself.
  • Put the last line of defense at the action: capability-scope high-blast actions; require a corroboration-independent confirmation or human-in-loop for irreversible ones (IFC / CaMeL).
  • Treat the outcome signal as attackable: don't let the agent write its own success labels (MINJA / reward-hacking) — source good/bad from reality or the owner.

Claim safety guide

Safe to assert

  • Source-counting is not Sybil-proof (Douceur 2002; Cheng & Friedman 2005).
  • Tiny-rate on-topic poison hijacks RAG/agent memory (PoisonedRAG; AgentPoison).
  • Detection latency is governed by a quickest-change lower bound (Lorden/CUSUM).
  • Historical winners were hybrids with a seed/anchor + behavior reputation.

Assert with caveat

  • "Outcome-accountability is better" — better as steady-state trust, not a standalone defense; assumes a trustworthy outcome oracle.
  • PoisonedRAG does not itself test corroboration/aggregation defenses — that step is our reasoning.
  • Market/funding figures are point-in-time snapshots.

Avoid / don't repeat

  • Any scheme "solves" or "walls" on-topic poison.
  • "Outcome-trust defeats Sybil" (it changes the currency).
  • Citing the "Dissociative Identity" preprint as evidence (framing only).

Contested signal

The "corroboration is broken" framing rests partly on a foil: the systems people actually ship (mem0, Letta) don't use source-count corroboration — they use user-scoped/authenticated writes and pre-insertion guards. So the strongest real-world claim is about isolation + outcome, not "corroboration is broken." The outcome-signal-forgeability objection (the oracle can be reward-hacked or self-written via MINJA) is a serious, unresolved limit on outcome-accountability, not a footnote. Preprints (e.g. "Dissociative Identity" 2605.30169 and recent memory-audit papers) are demoted to framing, not evidence.

The frontier question

In a single-owner store where the owner supplies ground-truth outcomes, can per-item retrieval isolation + outcome-accountability hold a poison's blast radius (damage × detection-latency) below the reversibility threshold of every action the agent is allowed to take — i.e., can the quarantine window be bounded tightly enough that residual latency never reaches an irreversible action?
